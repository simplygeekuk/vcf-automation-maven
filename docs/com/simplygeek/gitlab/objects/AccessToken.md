# Class `AccessToken`

Module: `com.simplygeek.gitlab.objects`

Defines the AccessToken class.

**Parameters:**

| Name | Type | Description |
|------|------|-------------|
| name | `string` | Name of the group access token. |
| scopes | `Array/string` | List of scopes. |
| expiresAt | `Date` | Expiration date of the access token in ISO format (YYYY-MM-DD). |
| accessLevel | `number` | Role (access_level) for group access token. |
